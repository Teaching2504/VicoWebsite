# VICO — Frontend

Frontend của website VICO, xây dựng bằng React và Vite.

## Chạy nhanh

Yêu cầu Node.js `20.19+` hoặc `22.12+`.

```powershell
npm install
npm run dev
```

Mở địa chỉ Local mà Vite hiển thị trong Terminal. Dừng server bằng `Ctrl + C`.

## Lệnh hữu ích

```powershell
npm run lint    # Kiểm tra code
npm run build   # Tạo bản production trong dist/
npm run preview # Xem thử bản production
```

README chính có phần giới thiệu nội dung website, hướng dẫn trình bày và cách thay ảnh/video: [../README.md](../README.md).
